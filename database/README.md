# البيانات
`migrations/001_foundation.sql` ينفذ مخطط المرحلة الأساسية، و`entity-map.json` يبقى خريطة نطاق كاملة.
يلزم company_id في كل كيان عمل ونطاق فرع/مخزن بحسب الحاجة.
المعتمد من البيع والمخزون والقيود يُكتب في معاملة واحدة مع sync_operations.
قيد دفتر متوازن مجموع المدين = مجموع الدائن لكل قيد وعملة.
دفعات جزئية ومتعددة ومرتجعات مرتبطة بالأصل؛ لا تعديل مباشر على أرصدة مشتقة.
فهرسة company_id ومعرف المستند والتاريخ والعميل والمخزن.
رقم مستند فريد ضمن الشركة والنوع والفترة؛ رقم أوف لاين مؤقت مستقل عن الرقم النهائي.
تخزين الزمن UTC وعرضه حسب منطقة الشركة. العملة ودقة المبلغ والكميات محددة.
طبّق المخطط بـ`npm run db:migrate`. استخدم مستخدم/قاعدة مستقلين عن شنو منو والمراقب.
لا يوجد ترحيل تلقائي من MongoDB القديم.

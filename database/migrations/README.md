# database/migrations

migrations إصدارية لمخطط PostgreSQL.

`001_foundation.sql`: الشركات والفروع والمستخدمون والأدوار والجلسات والمزامنة والتدقيق
والأساس المالي، مع RLS وقيود append-only.
`002_commerce.sql`: المواد والوحدات والأسعار والعملاء والموردون والمخازن والأرصدة
والمستندات والدفعات وحركات المخزون وserver outbox، مع RLS وقيود عدم التعديل والحذف.
`003_pos.sql`: الباركود وأجهزة الكاشير وسياسات الخصم والشفتات ومخصصات الأوف لاين
والوصولات وربط مستند البيع بالشفت وواجهة النشاط.

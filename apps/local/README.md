# المحاسب برو المحلي — نسخة أولية

من جذر المستودع، باستخدام Node.js 18 أو أحدث:

```sh
node apps/local/server.cjs
```

على لينكس لتشغيل الخادم وفتح نافذة التطبيق مع خيار الطباعة الصامتة:

```sh
bash apps/local/start-linux.sh
```

أبق الطرفية مفتوحة أثناء العمل. يلزم إعداد الطابعة الافتراضية مسبقًا؛ خيار Chrome لا يضمن عمل فتح الدرج أو الطباعة على كل طابعة.

افتح `http://127.0.0.1:3210` واستعد نسخة الكاشير الاحتياطية من الموقع، ثم افتح الكاشير. لا تغيّر عنوان التشغيل أو منفذه: IndexedDB وlocalStorage مرتبطان بعنوان المتصفح. لا تُنقل البيانات من Render تلقائيًا. استخدم ملف متصفح ثابتًا واحتفظ بنسخ احتياطية.

الواجهة تُقرأ من ملفات الجهاز، والحسابات والحركات تُحفظ في التخزين المحلي الموجود. لا يحتاج بدء التشغيل إلى اتصال أو اعتماديات npm. يستمع الخادم على loopback فقط ولا يعرض الملفات خارج قائمة الكاشير. لا يُعد هذا نظام دخول محلي متعدد المستخدمين؛ أمان الجهاز وحساب نظام التشغيل مطلوبان.

لم تُوصل المزامنة السحابية بعد: API تُرجع 503 ولا تعترف بعمليات كأنها متزامنة. ماسح الهاتف الحالي يعتمد على الخادم السحابي؛ استخدم قارئ USB أو إدخال الباركود في هذه المرحلة. الربط الشبكي والطباعة الحرارية يحتاجان اختبارًا على جهاز المستخدم.

الاختبارات: `node tests/local-runtime.test.cjs` و`node tests/market-cashier-persistence.test.cjs`.

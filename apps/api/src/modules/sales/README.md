# محرك البيع المشترك

طلب، فاتورة، دفعات نقدية وآجلة ومختلطة؛ مرتجع مرتبط بالأصل؛ اعتماد ذري مع المخزون والمالية.

الحالة: اعتماد البيع والدفعات النقدية/الآجلة والمرتجع والمخزون والقيد الذري منفذ.
واجهات الوحدة المستقبلية: routes، service، repository، validation؛ لا وصول مباشر لوحدة أخرى إلى جداولها دون عقد معلوم.

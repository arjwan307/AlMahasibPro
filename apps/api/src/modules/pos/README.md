# الكاشير

أجهزة وشفتات وفتح وإغلاق وتسوية الصندوق والطباعة؛ مخزون مخصص للأوف لاين.

الحالة: الأجهزة والشفتات والعهدة والبيع والمرتجع والوصل والتسوية ومخصص الأوف لاين منفذة.
الطابعات الحرارية وتجارب الأجهزة الفعلية باقية.
واجهات الوحدة المستقبلية: routes، service، repository، validation؛ لا وصول مباشر لوحدة أخرى إلى جداولها دون عقد معلوم.

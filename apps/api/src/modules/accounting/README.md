# المحاسبة

دليل حسابات، قيود مزدوجة، فترات، ذمم، تسويات؛ مستندات عكسية بدل الحذف.

الحالة: أساس قاعدة البيانات وقيود عدم الحذف وعكس القيود والتوازن منفذة؛ خدمات المحاسبة
ودليل الحسابات والترحيل من وحدات الأعمال باقية.
واجهات الوحدة المستقبلية: routes، service، repository، validation؛ لا وصول مباشر لوحدة أخرى إلى جداولها دون عقد معلوم.

# المخازن

حركات مخزون موثقة؛ استلام وتجهيز وتحويل وحجز وجرد وتالف؛ السيارة مخزن مستقل.

الحالة: المخازن والأرصدة ومتوسط التكلفة والحركات الناتجة من التجارة منفذة؛ التحويل والجرد باقٍ.
واجهات الوحدة المستقبلية: routes، service، repository، validation؛ لا وصول مباشر لوحدة أخرى إلى جداولها دون عقد معلوم.

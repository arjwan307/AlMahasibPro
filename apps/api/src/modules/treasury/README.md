# الصندوق والبنوك

توفر المسارات `/api/v1/treasury/cashboxes` تعريف صندوق IQD أو USD وفتح جلسة، وتسجيل قبض أو صرف مقابل حساب دليل الحسابات، وإغلاق بعد إدخال النقد المعدود. فروق الزيادة والعجز ترحل بقيود ظاهرة. يحتسب المتوقع من القيود المحاسبية على حساب الصندوق خلال الجلسة، بما فيها التسويات والرواتب والمبيعات النقدية.

الحالة: الأساس التشغيلي مرتبط بمخزن SQLite ومحرك القيود؛ التحويلات بين الصناديق والتسوية البنكية وكشوف الطباعة تحتاج استكمالًا.

# الحسابات والمصادقة

تسجيل الشركة واعتمادها؛ الجلسات؛ كلمات مرور مشفرة؛ إلغاء الجلسات.

الحالة: تسجيل الشركة والدخول والجلسات والإلغاء منفذة ضمن API الأساسي؛ إدارة الاسترداد
والتحقق الإضافي ما زالت مطلوبة.
واجهات الوحدة المستقبلية: routes، service، repository، validation؛ لا وصول مباشر لوحدة أخرى إلى جداولها دون عقد معلوم.

# المزامنة والأوف لاين

سجل عمليات محلي append-only؛ push/pull وأرقام إصدارات؛ إعادة محاولات ومنع تكرار وتعارضات.

الحالة: push/pull/status ومنع التكرار وعميل IndexedDB منفذة كأساس؛ تعارضات الوحدات باقية.
واجهات الوحدة المستقبلية: routes، service، repository، validation؛ لا وصول مباشر لوحدة أخرى إلى جداولها دون عقد معلوم.

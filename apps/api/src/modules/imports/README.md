# الاستيراد والشحن

يسجل المسار `/api/v1/import/shipments` المورد والحاوية والمنشأ وبوليصة الشحن، ثم يثبت الوصول ويربط فاتورة شراء مرحّلة من المورد نفسه. تُدخل أجور الشحن والجمارك والتأمين والمناولة كبنود، وتوزع على أصناف الفاتورة. ينشئ الترحيل قيدًا في الأستاذ، ويرسمل الجزء الموافق للبضاعة الموجودة بالمخزون ويحمّل تكلفة الجزء المباع على تكلفة البضاعة.

الحالة: الأساس التشغيلي مربوط بعزل الشركة والصلاحيات وSQLite، مع منع التكرار وفحص التوازن. لا توجد بعد إدارة مستندات جمركية إلكترونية أو تحويل العملات المتعددة داخل مستندات الاستيراد.

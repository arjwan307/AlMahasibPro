# الرواتب

مسارات `hr` تحفظ الموظفين والعقود والمخصصات والاستقطاعات والسلف ودورات الرواتب في مخزن الشركة. دورة الراتب تمر بالمسودة والمراجعة والاعتماد والصرف؛ الاعتماد ينشئ قيد الاستحقاق، والصرف ينشئ قيد النقدية، والتسويات تسجل بقيد مستقل. معرف العملية يمنع تكرار قيد السلفة أو الاعتماد أو الصرف.

الحالة: الأساس التشغيلي متاح عبر API ومخزن SQLite. احتساب الغياب يعتمد إعداد أيام العمل والحضور المتاح؛ لا يتضمن بعد تقويم عطلات مؤسسي أو دورة اعتماد متعددة المستويات قابلة للتهيئة.

# الرواتب

مسارات `hr` تحفظ الموظفين والعقود والمخصصات والاستقطاعات والسلف والحضور والإجازات والعمل الإضافي ودورات الرواتب في مخزن الشركة. الحضور يسجل من خلال عملية مزامنة ثابتة المعرف؛ الإجازة لا تؤثر على كشف الراتب حتى اعتمادها، ويحدد المدير عند الاعتماد كونها مدفوعة. الإجازات المتداخلة وطلبات الإضافي المكررة في اليوم الواحد مرفوضة. يخصم الراتب الإجازة غير المدفوعة حتى عندما لا يكون تتبع الحضور مطلوبًا، ولا تجمع دورة رواتب فترتين متداخلتين.

تمر دورة الراتب بالمسودة والمراجعة والاعتماد والصرف؛ الاعتماد ينشئ قيد الاستحقاق ويطبق أقساط السلف مرة واحدة بالترتيب، والصرف ينشئ قيد النقدية، والتسويات تسجل بقيد مستقل. معرف العملية يمنع تكرار الحضور أو قيد السلفة أو الاعتماد أو الصرف.

تظهر إدارة الموظفين والرواتب والحضور في لوحة الشركة لحسابات الموارد البشرية والمحاسبين وفق صلاحياتها؛ إدارة الصندوق والاستيراد تظهر في تبويبيهما وتستدعي المسارات نفسها التي تتحقق من الشركة والصلاحية.

الحالة: الأساس التشغيلي متاح عبر API ومخزن SQLite. احتساب الغياب يعتمد أيام العمل الشهرية وإعداد الحضور؛ لا يتضمن بعد تقويم عطلات مؤسسيًا أو دورة اعتماد متعددة المستويات قابلة للتهيئة.

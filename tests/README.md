# tests

عزل شركات، اعتماد ذري، منع تكرار، انقطاع مزامنة، تضارب مخزون، عهدة ورواتب وطباعة واستعادة.

الحالة: اختبارات المرحلة الأساسية منفذة في `tests/integration`: المصادقة والاعتماد
والصلاحيات والعزل ومنع التكرار وPostgreSQL وقيود السجلات المالية، إضافة إلى المواد
وتحويل الوحدات والتجارة والمرتجعات والدفعات ودقة الكسور والفشل الذري. سيناريوهات الشفتات
والواجهات الثلاث والخصم والمخصص والتسوية ومنع التكرار منفذة أيضًا. تجارب الطابعات
الحرارية والأجهزة الفعلية والمندوبين ما زالت مطلوبة.

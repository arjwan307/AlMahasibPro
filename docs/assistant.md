# المساعد الذكي

واجهة المحادثة الأولى مستوحاة من مساعد «الصديق الذكي» في شنو منو، ومكيّفة للمحاسب برو.
هذه المرحلة توفر المحادثة النصية فقط؛ لا تقرأ بيانات الشركة، ولا تنفذ بحثًا أو تعديلاً أو
اعتمادًا أو ترحيلاً. يرسل الخادم المحادثة إلى خدمة Ollama المضبوطة، ولا يقبل عنوان الخدمة
من المتصفح.

## تشغيل نموذج محلي

1. شغّل خدمة Ollama على جهاز الخادم أو في شبكة خاصة موثوقة.
2. نزّل نموذجًا مناسبًا للذاكرة المتاحة؛ الإعداد الافتراضي هو `qwen3:4b`.
3. اضبط `AI_ASSISTANT_OLLAMA_URL` و`AI_ASSISTANT_MODEL` في بيئة تشغيل API.
4. أعد تشغيل API. تعرض الواجهة حالة النموذج تحت عنوان المساعد.

لا يوضع مفتاح خدمة في المتصفح. يمكن ضبط `AI_ASSISTANT_LOCAL_API_KEY` عند استعمال وسيط
خاص يدعم مصادقة Bearer. المحادثة تبقى في ذاكرة صفحة المستخدم الحالية ولا تحفظها قاعدة
البيانات في هذه المرحلة.

## التوسعات التالية

إضافة البحث والتذكيرات والشرح التشغيلي كأدوات مستقلة، مع احترام صلاحيات المستخدم ونطاق
الشركة. تبقى القيود المالية وحركات المخزون والرسائل الخارجية خلف معاينة وموافقة صريحة.

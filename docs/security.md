# قبل الإنتاج
يوجد .env متتبع في المستودع العام الأصلي. لا يُعاد تضمينه في هذه الحزمة.
يجب مراجعة ما إذا كانت قيمه حقيقية، وتدوير أي أسرار منشورة من جهة المزود، ثم إزالة الملف من التتبع والتاريخ حسب الحاجة.
استُبدل الدخول التجريبي بمصادقة خادم وكلمات مرور scrypt مملحة وجلسات opaque مخزن منها
hash فقط، مع cookie HttpOnly/SameSite وحد محاولات أولي. يجب تفعيل TLS وSecure cookies
ومحدد محاولات مشترك (مثل Redis) عند التشغيل متعدد النسخ.
كل طلب يتحقق من الشركة والدور والنطاق؛ لا تعرض أخطاء قاعدة أو الأسرار للعميل.
سياسات PostgreSQL RLS مفعلة مع FORCE على جداول المستأجر. استخدم مالك migrations منفصلًا
عن مستخدم التطبيق، وامنح مستخدم التطبيق أقل الصلاحيات؛ لا تشغّل API بمستخدم superuser.
الـCORS مقيد بـ`ALLOWED_ORIGINS`، ولا تضع عنوان إنتاج مفتوحًا أو wildcard مع الكوكيز.
QR لا يحتوي كلمات مرور أو كامل بيانات العميل؛ معرّف مستند ورابط/توكن محدود الصلاحية بحسب المشاركة.
لا تعطِ فرق الدعم وصولًا دائمًا إلى بيانات الشركات دون سياسة موثقة.

# المحاسب برو — نسخة الشركات على ويندوز

هذه النسخة تثبت تطبيق سطح مكتب مستقلًا، وتستخدم SQLite على جهاز الشركة. لا يلزم تثبيت Node.js أو MongoDB لدى العميل ولا يلزم إنترنت لبدء العمل. يختار العميل اسم الشركة واسم المدير واسم المستخدم وكلمة المرور عند أول تشغيل. لا يوجد حساب مطور مخفي أو كلمة مرور مشتركة، ولا يحتاج الإعداد المحلي اعتماد منصة خارجية.

## الوظائف المتاحة

- أصناف Item، بحث بالكود والاسم، وحدات أساسية وإضافية ومعامل تحويل وأسعار.
- مخازن وأرصدة وتكلفة مخزون، سندات تحويل بين المخازن بالوحدة الأساسية.
- عملاء وموردون، شراء وبيع نقدي وآجل ومختلط.
- ترحيل ذري للمستند إلى المخزون والقيد المتوازن، ومنع بيع مخزون غير متوفر.
- عرض وطباعة المستندات، مرتجع كامل للمستند قبل تسوية ديونه.
- سندات قبض ودفع على المستندات، ومنع تجاوز المبلغ المستحق.
- دفتر القيود، كشف مخزون، تصدير CSV.
- إنشاء مستخدمين بأدوار مدير ومحاسب وأمين مخزن وكاشير ومدقق.
- تنزيل نسخة احتياطية SQLite للمدير، واستعادتها من قائمة الملف مع حفظ نسخة سابقة وإلغاء جلسات النسخة المستعادة.

## تشغيل العميل

1. شغّل المثبت واختر المجلد؛ ينشئ اختصارًا على سطح المكتب وقائمة ابدأ.
2. شغّل التطبيق وأكمل إعداد الشركة. كلمة المرور لا تقل عن عشرة أحرف.
3. سجّل الدخول، ثم عرّف الوحدات والمخازن والأصناف والأطراف.
4. سجّل مشتريات لإدخال الرصيد، ثم اختبر المبيعات والتحصيل والتحويل.
5. نزّل نسخة احتياطية واحتفظ بها خارج الجهاز بانتظام.

المثبت يثبت لكل مستخدم ويندوز. قاعدة البيانات في مجلد بيانات التطبيق لذلك المستخدم، خارج مجلد البرنامج؛ إزالة التطبيق لا تمسح بيانات الشركة. وجود حسابات متعددة داخل التطبيق لا يجعل قاعدة البيانات مشتركة تلقائيًا بين حسابات ويندوز المختلفة.

## حدود هذه النسخة

لا تزال المزامنة التلقائية لقاعدة الجهاز مع خادم بعيد غير موصولة. واجهة الشركات يمكن تقديمها عبر خادم المشروع، لكن ذلك لا يعني أن قاعدة الجهاز تتزامن معه. ولا يوجد ربط تلقائي بين نسخ مثبتة على عدة أجهزة. لا تعتمد هذه النسخة لتشغيل عدة مواقع على بيانات مشتركة قبل تنفيذ الربط واختبار التعارضات.

الفواتير ذات سندات تسوية تحتاج مسار عكس تسوية قبل إرجاعها؛ هذا المسار، والمرتجع الجزئي في واجهة الشركات، وتعديل/تعطيل المستخدمين، ومسارات الإنتاج والرواتب داخل هذه الواجهة غير مكتملة. لم يُنفذ اختبار فعلي للمثبت على جهاز ويندوز؛ البناء والتحقق من المحرك تمت في بيئة لينكس. المثبت غير موقّع رقميًا.

## البناء من المصدر

استخدم Node.js 24 وnpm، ثم:

```sh
npm ci
npm run desktop
npm run build:windows -- --x64
```

للتشغيل المحلي دون Electron أثناء التطوير:

```sh
npm run start:enterprise
```

الاختبارات الآلية: `npm test` واختبارات `.cjs` الحالية للكاشير المحلي. اختبار SQLite يغطي أول إعداد، عدم وجود حساب مطور، حفظ الشراء والبيع والتحصيل والتحويل، رفض تجاوز الرصيد، التراجع عن تحويل متعدد البنود فاشل، النسخ الاحتياطي وإعادة التشغيل.

# المحاسب برو — الإصدار 1.2.0

تحديث تنسيق واجهات الشركات ونقاط البيع: أزرار أصغر، خطوط ومسافات متناسقة، وقوائم قابلة للطي لعرض البيانات عند الحاجة.

- اضغط عنوان القائمة لفتحها أو إخفائها. يمكنك البحث واختيار «عرض الكل» أو التصفية بحسب الأعمدة المتاحة: الفرع، المخزن، التصنيف، النوع أو الحالة.
- قوائم فواتير الشركة تعرض الفرع. المخزون يعرض الفرع والمخزن. الموردون قابلون للبحث والتصفية حسب الدولة.
- اضغط علامة «!» لعرض الإرشاد، واضغطها مرة أخرى أو اضغط Escape لإغلاقه.
- طباعة وتصدير قوائم الشركة يحترمان البحث والتصفية، حتى عند طي القائمة. بنود الفاتورة الجارية تبقى ظاهرة أثناء الإدخال.
- الواجهة مناسبة للهاتف والآيباد، وتستخدم خطوط الجهاز عند العمل دون الإنترنت.

## تثبيت التحديث

أغلق النسخة القديمة ثم شغّل مثبت الإصدار 1.2.0. لا تمسح مجلد بيانات البرنامج؛ يحتفظ المثبت ببيانات الشركة المحلية. يُفضّل أخذ نسخة احتياطية من داخل البرنامج قبل التحديث.

تشغيل الشركة محليًا والمزامنة اليدوية والآلية والنسخ الاحتياطي مستمران كما في الإصدار 1.1.0. ربط السحابة أول مرة يحفظ نسخة محلية ثم يعتمد بيانات الشركة السحابية بعد موافقتك في نافذة الربط.

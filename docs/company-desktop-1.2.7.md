# المحاسب برو للشركات 1.2.7

- القيود الافتتاحية: مسودات محفوظة، مصدر كل رصيد، اعتماد المدير ومنع الترحيل المكرر.
- الأستاذ العام، الأرباح والخسائر، الميزانية والتدفقات النقدية مع الطباعة وCSV.
- سندات إغلاق الصندوق، جرد النقد ومراجعة المدير، ورفض الجرد المتقادم والقيود المتأخرة على الشفت المغلق.
- إقفال الفترات مع قيود ختامية ونقل النتيجة إلى الأرباح المرحلة.
- صلاحيات مستقلة لعرض الصندوق وإدارته، وتسميات عربية للشحن والاستيراد.
- تشغيل محلي بقاعدة SQLite، مع بقاء بيانات الشركات الحالية عند التحديث.

نسخة Windows x64. يجري النشر بعد نجاح اختبارات النظام وبناء المثبّت وفحص التشغيل المحلي للحزمة. ملف SHA-256 مرفق للتحقق من سلامة التنزيل.

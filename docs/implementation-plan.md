# ترتيب التنفيذ
1. **منجز جزئيًا:** PostgreSQL والمناطق الزمنية والعملة؛ جرد البيانات القديمة والأجهزة والطابعات باقٍ.
2. **منجز كأساس:** مصادقة وعزل شركات وفروع وصلاحيات وجلسات وسجل تدقيق.
3. المواد والوحدات والأسعار والعملاء والموردون والمخازن وحركاتها.
4. محرك البيع والشراء والدفعات والمحاسبة بمعاملات ذرية.
5. الكاشير والشفتات والواجهات الثلاث مع المحافظة على التصميم.
6. المندوب ومخزن السيارة والتحصيل والعهد.
7. الموظفون والحضور والإجازات والرواتب وترحيلها للمالية.
8. **أساسه منجز:** push/pull والطابور ومنع التكرار؛ تُدمج عمليات الوحدات منذ المرحلة 3 ثم اختبارات انقطاع شاملة.
9. أندرويد والطباعة وتجارب الأجهزة والتقارير والنسخ الاحتياطي.
10. نشر مستقل بعد اختبار المسارات.

لا إنشاء خدمة مدفوعة أو ترحيل بيانات أو رفع GitHub قبل إكمال واختبار الوحدات.

# المسارات
## البيع
شفت مفتوح → مسودة → تحقق السعر والصلاحية والمخزون → دفع/آجل → اعتماد ذري → وصول → مزامنة عند الحاجة.
## شراء
طلب → أمر → استلام مخزني → فاتورة → التزام مورد/دفع؛ الاستلام لا يُكرر عند الفاتورة.
## مندوب
تخصيص مخزن سيارة → تحميل بتحويل → بيع/طلبات → تحصيل بعهدة → مرتجع → تسليم نقد ومخزون → مراجعة.
## مخازن
مسودة حركة → اعتماد → إدخال/إخراج؛ التحويل طرفان مرتبطان؛ الجرد تسوية موثقة لا استبدال رصيد.
## رواتب
فترة → حضور وإضافي معتمد → احتساب أساس وبدلات وسلف واستقطاعات → مراجعة → اعتماد → صرف → قيد.
قفل الدورة بعد الاعتماد؛ إعادة الاحتساب تنتج نسخة مسودة ولا تصرف الراتب مرتين.
## مطاعم
طاولة/سفري → طلب → مطبخ → تسوية/تقسيم حساب → بيع؛ استهلاك المكونات حسب وصفة معتمدة.

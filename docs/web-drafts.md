# حماية الحقول أثناء التحديث والمزامنة

تستمر المزامنة وتنزيل بيانات الخادم، لكن صفحة الشركة لا يعاد بناؤها أثناء إدخال
بيانات غير محفوظة. تشمل الحماية الحقول النصية والملاحظات والاختيارات والصلاحيات
والملفات والنوافذ المفتوحة وأطراف القيود وصفوف إدخال المخزون ومسودات البيع والشراء.

يحتفظ المتصفح بقيم البداية في WeakMap للمقارنة فقط؛ لا يرسل محتوى المسودة للخادم
ولا يحفظ كلمات المرور أو المسودات في تخزين دائم. تفرغ النماذج بعد نجاح الحفظ المعتاد،
وتبقى بياناتها عند رفض الحفظ. الصفحات التي لا تحتوي عملًا غير محفوظ تستمر في تحديث عرضها.

يعيد refresh({background:true}) فحص المسودة بعد انتهاء طلبات القراءة. إذا بدأ المستخدم
الكتابة أو الحفظ أو انتقل لصفحة أخرى أثناء الانتظار، يستبعد الرد ولا يستبدل حالة الصفحة
أو عناصرها. ردود تحميل شاشة المبيعات، بما فيها ردود الخطأ، مرتبطة بمراجعة العرض والطلب
حتى لا يستبدل طلب قديم شاشة أحدث. تحديث البيانات والمزامنة اليدوية وتحديث صور المواد
تحترم هذه الحماية. الحفظ الصريح يعيد العرض بعد نجاحه كما كان سابقًا.

لا تغير هذه الحماية صلاحيات أو قواعد التحقق والحفظ، ولا تحفظ معاملات في الخلفية.
استعمالها داخل واجهة الويب المشتركة لا يعني صدور مثبت Windows جديد.

التحقق: tests/browser/workspace-draft-preservation.mjs يستخدم التطبيق والمزامنة الحقيقيين
مع بيانات اختبار، ويغطي 13 قسمًا بالإضافة للمبيعات، والنصوص والاختيارات والصلاحيات
وصفوف المخزون والنوافذ والتحديث أثناء الكتابة وردود الشبكة المتأخرة والحفظ الناجح والمرفوض.

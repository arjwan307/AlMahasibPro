# المحاسب برو الشامل

نُفذت المرحلة الأساسية والتجارية للخادم وقاعدة البيانات: PostgreSQL، الهوية والعزل،
المواد والأطراف والمخازن، واعتماد الشراء والبيع والمرتجعات والدفعات مع المزامنة.
كما نُفذت شفتات الكاشير والواجهات الثلاث ومخصصات الجهاز للأوف لاين وتسوية الصندوق.
ونُفذت دورة المندوب المتحرك للويب: المسار ومخزن السيارة والطلبات والبيع والمرتجعات
والتحصيل وعهدة النقد والبضاعة والمراجعة والمزامنة.
لا تزال وحدات الأعمال التالية قيد التنفيذ ولا تعد هذه نسخة إنتاج مكتملة.

## نطاق المشروع
كاشير بثلاث واجهات: مطاعم وكافيهات، ماركتات، شركات ومؤسسات.
مخازن ومالية وموظفون ورواتب ومندوبون متحركون، مع أوف لاين ومزامنة عند الفتح.

## دليل الحزمة
- public/: التصاميم الأصلية مع ربط الدخول وحارس الجلسة والمزامنة دون تغيير CSS أو التخطيط.
- server.js: نقطة تشغيل API الجديدة، PostgreSQL افتراضيًا ومخزن ذاكرة للاختبار فقط.
- apps/web/: تنظيم الواجهة المستقبلية.
- apps/api/: تطبيق API ومخازن PostgreSQL والذاكرة.
- apps/android/: تطبيق Kotlin المقترح للكاشير والمندوب.
- packages/: التصميم المشترك والعقود والمحرك المحلي.
- database/: migration PostgreSQL وأداة التطبيق وإنشاء مدير المنصة.
- docs/: البنية والصلاحيات ومسارات التشغيل والمزامنة والمقارنة وخطة التنفيذ.
- infra/: عزل الاستضافة والتخزين والنسخ الاحتياطي.
- tests/: خطة التحقق قبل الإنتاج.

لم تُنقل الصفحات إلى apps/web ولم يتغير شكلها المرئي. اقرأ docs/security.md وdocs/progress.md قبل أي نشر.

## التشغيل المحلي
1. انسخ `.env.example` إلى `.env` وأدخل `DATABASE_URL` لقاعدة مستقلة.
2. شغّل `npm install` ثم `npm run db:migrate`.
3. عيّن بيانات مدير المنصة وشغّل `npm run seed:platform-admin`.
4. شغّل `npm start` ثم افتح `http://localhost:5000`.

يمكن استخدام `DATA_STORE=memory npm start` للعرض المؤقت فقط؛ يفقد بياناته عند الإغلاق.
شغّل `npm test` للاختبارات، ومرر `TEST_DATABASE_URL` لإضافة اختبار PostgreSQL الفعلي.

## قرارات تحتاج تثبيتًا
PostgreSQL معتمد للمعاملات المالية؛ لا ترحيل لقاعدة MongoDB القديمة دون جرد البيانات.
Kotlin لأندرويد، وIndexedDB للويب؛ الطابعات والأجهزة المستهدفة تُحدد قبل تنفيذ ربطها.
الضرائب والرواتب والعملات وفترات العمل إعدادات تُثبت بحسب الشركة.
